# 다이머 러시 (Dimer Rush)

프라이머 다이머를 일부러 만드는 퍼즐 게임. 8염기 조각을 둘씩 짝지어 ΔG 합이 가장 낮은 조합을 찾는다.

## 실행

빌드 없음. `index.html`과 `boards.js`를 같은 폴더에 두고 연다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 규칙

- 조각 두 개를 탭하면 둘째 조각이 뒤집혀(역평행) 가장 잘 붙는 위치로 맞물린다.
- 미리보기는 결합선만 보여 준다. ΔG 숫자는 결합한 뒤에 나온다.
- 점수 = −ΔG × 100. 3′ 끝이 결합 구간에 물리면 ×1.5, 양쪽 다 물리면 ×2.
- 튜브 3개(70·70·80초). 전부 결합하면 남은 시간 1초당 5점.
- 튜브가 끝나면 내 조합과 최적 조합을 나란히 보여 준다. 성적은 최적 대비 비율을 NTC Ct(22~38)로 환산한다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 화면, 조작, 점수 집계 |
| `boards.js` | 미리 계산한 보드 180개(튜브당 60개)와 쌍별 결과 |

ΔG 계산 엔진은 이 저장소에 없다. 보드는 별도 생성기로 만들고, 게임은 `boards.js`의 결과값만 읽는다.
